# 움짤 메이커 (Umzzal Maker)

### 👉 [바로 사용하기](https://riam-zen.github.io/umzzal-maker/)

설치할 필요 없이 브라우저에서 바로 쓰는 움짤 제작 도구입니다.
이미지 여러 장을 넣으면 **GIF · 애니메이션 WebP · 레이어 PSD**로 저장해 줍니다.
모든 작업이 내 컴퓨터 안에서만 처리되고, 이미지는 어디로도 전송되지 않습니다.

---

## 주요 기능

- **장면 편집**: 이미지를 끌어다 놓아 추가하고, 장면마다 순서·유지 시간(초)·전환 효과를 정합니다. 장면을 교체하거나 사이에 끼워 넣을 수도 있습니다.
- **전환 효과 20종**: 페이드, 슬라이드, 밀어내기, 와이프, 줌, 원형 열기, 플래시 등
- **전체 재생 속도**: 0.25~4배 (예: 1초 장면 + 2배속 → 0.5초)
- **출력 크기**: 원본 크기(배율) 또는 지정 크기. 맞춤 방식은 크롭 / 여백 / 늘리기, 기준 위치는 9방향
- **고정 로고**: 장면이 바뀌어도 맨 위에 고정. 위치·크기·여백·불투명도 조절
- **용량 제한**: 5MB, 10MB 등 목표 용량을 넘으면 화질 → 프레임 수 → 해상도 순서로 자동으로 줄여서 맞춤
- **저장 형식**: GIF, 애니메이션 WebP, 레이어가 살아 있는 PSD(배경 / 장면별 / 로고)
- **다시 열어서 편집**
  - 프로젝트 파일(`.umzzal.json`): 원본 이미지와 모든 설정이 들어 있어 그대로 이어서 편집할 수 있습니다.
  - PSD: 장면 레이어와 로고를 다시 불러옵니다. 포토샵에서 수정한 파일도 됩니다.
  - GIF·WebP: 프레임 단위로 불러옵니다.
- **화면 테마**: ☀️ 밝게 / 🌓 중간(포토샵 스타일) / 🌙 어둡게

## 사용 방법

1. 왼쪽 칸에 이미지를 끌어다 놓습니다.
2. 장면마다 유지 시간과 전환 효과를 정합니다. "모두에 일괄 적용"으로 한 번에 바꿀 수도 있습니다.
3. 오른쪽에서 크기·로고·용량 제한을 설정합니다.
4. **GIF 저장 / WebP 저장 / 레이어 PSD 저장**을 누릅니다.
5. 나중에 다시 고칠 작업이라면 **💾 프로젝트 저장**도 해 두세요.

## 참고

- **크롬 또는 엣지를 권장합니다.** WebP 저장과 GIF·WebP 불러오기는 이 두 브라우저에서 됩니다.
- GIF는 프레임마다 256색까지만 표현할 수 있어서, 사진이 많은 이미지는 WebP가 더 깨끗합니다.
- PSD는 8비트 RGB 파일만 불러올 수 있습니다.
- 오프라인으로 쓰려면 `index.html`을 내려받아 브라우저로 열면 됩니다.
